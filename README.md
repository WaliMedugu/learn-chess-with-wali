# ♟️ LearnChessWithWali

> **An interactive, AI-powered chess trainer and sparring platform built with Flutter.**

LearnChessWithWali is a full-featured chess companion designed to accelerate player mastery. Featuring real-time game state analysis, interactive board controls, customizable AI sparring personalities (White, Black, or Random choice), custom move history, and integrated tactical guidance.

---

## ✨ Features
- **Intelligent Chess AI Engine**: Spar against customizable AI difficulty tiers with human-like move pacing and dynamic evaluation.
- **Side Selection & Game Modes**: Play as White, Black, or allow the AI to randomly assign sides before starting.
- **Interactive Move Validation**: Full legal move calculation, check/checkmate detection, and highlighted target paths.
- **Move Log & Time Controls**: Complete algebraic notation move history with turn timers and blitz modes.
- **Modern Responsive UI**: Fluid animations, custom piece themes, and sound effects built with Flutter.

---

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK (>= 3.0.0)

### Installation & Run
```bash
git clone https://github.com/WaliMedugu/learn-chess-with-wali.git
cd learn-chess-with-wali
flutter pub get
flutter run
```
